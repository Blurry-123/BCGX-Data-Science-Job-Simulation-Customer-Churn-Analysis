
# BCGX Data Science Job Simulation – Customer Churn Analysis

## Overview

This project was completed as part of the Data Science Job Simulation by BCGX on Forage. The simulation focused on analyzing customer churn data for a fictional analytics company and developing machine learning solutions to help improve customer retention strategies.

The project involved data preprocessing, exploratory data analysis, predictive modeling, and presenting business insights through an executive summary.

---

## Business Problem

Customer churn is a major challenge for businesses because losing customers directly impacts revenue and growth. The objective of this project was to analyze customer behavior data, identify churn patterns, and build a predictive model capable of identifying customers likely to leave the company.

---

## Objectives

* Analyze customer data to identify churn patterns
* Perform data cleaning and preprocessing
* Build and optimize a machine learning model
* Evaluate model performance
* Deliver actionable business insights

## Project Workflow

### 1. Data Preprocessing

* Cleaned and prepared customer data
* Handled missing values
* Encoded categorical variables
* Performed feature selection

### 2. Exploratory Data Analysis

* Analyzed customer demographics and behavior
* Identified trends contributing to churn
* Created visualizations for better interpretation

### 3. Machine Learning Model

* Built a Random Forest Classifier model
* Optimized model parameters
* Evaluated model performance using recall score

### 4. Results

* Achieved a recall score of 50% in churn prediction
* Identified important factors influencing customer churn
* Generated insights to support customer retention strategies

## Key Insights

* Customer behavior patterns can strongly indicate churn risk
* Data-driven decision-making can improve customer retention
* Machine learning models can help businesses proactively identify at-risk customers
